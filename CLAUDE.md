# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Commands

```bash
uv sync                  # install dependencies
uv run run.py            # start dev server on :5000
uv run seed.py           # create tables and load CSV seed data
createdb hackathon_db    # run once before first seed
```

## Environment

Copy `.env.example` to `.env`. Required vars: `DATABASE_NAME`, `DATABASE_HOST`, `DATABASE_PORT`, `DATABASE_USER`, `DATABASE_PASSWORD`.

## Architecture

**Stack:** Flask · Peewee ORM · PostgreSQL · uv

**App factory:** `run.py` → `create_app()` (`app/__init__.py`) → `init_db()` → import models → `register_routes()`.

**Database proxy:** `app/database.py` exports a `DatabaseProxy` (`db`) and `BaseModel`. The proxy is initialized in `init_db()` so models can be defined before the connection exists. Connections open per-request via `before_request`, close via `teardown_appcontext`.

**Models** (`app/models/`):
- `User` — `id, username, email, api_key, created_at`
- `Url` — `id, user_id, short_code (6 chars, unique), original_url, title, is_active, created_at, updated_at`
- `Event` — `id, url_id, user_id, event_type, timestamp, details (raw JSON string)`

Event types: `created | updated | deleted | clicked`. The `details` field is stored as a raw JSON string — use `json.loads()`/`json.dumps()` when reading/writing.

**Indexes** (defined in model `Meta.indexes`): `Url.short_code` (unique), `Url.user_id`, `Event.url_id`, `Event.user_id`, `Event.event_type`.

**Key modules:**
- `app/auth.py` — `@require_auth` decorator (reads `X-API-Key` header, injects `g.current_user`); `assert_owner(url, user)` → 403
- `app/utils.py` — `generate_short_code()` generates a collision-safe 6-char alphanumeric code
- `app/events.py` — `log_event(url_id, user_id, event_type, details, async_=False)`; pass `async_=True` on redirects to avoid blocking

**Routes:**
| Method | Path | Auth | Description |
|--------|------|------|-------------|
| GET | `/<short_code>` | no | Redirect to original URL (302); logs `clicked` event async |
| POST | `/api/urls/` | yes | Create short URL |
| GET | `/api/urls/<id>` | no | Get URL detail |
| PATCH | `/api/urls/<id>` | yes, owner | Update title/original_url/is_active |
| DELETE | `/api/urls/<id>` | yes, owner | Soft delete (sets is_active=False) |
| GET | `/api/users/<id>/urls` | no | Paginated list of user's URLs |
| GET | `/api/users/<id>/events` | no | Paginated list of user's events |
| GET | `/api/urls/<id>/events` | no | Paginated event history for a URL |

Pagination params: `?page=1&per_page=20` (max per_page: 100).

**Auth:** Pass `X-API-Key: <key>` header. API keys are generated by `seed.py` and printed for the first 5 users. To get a key for any user: `User.get_by_id(n).api_key` in a Python shell.

**Seeding:** `seed.py` creates tables, then bulk-inserts CSVs from `../users.csv`, `../urls.csv`, `../events.csv` (one directory above the project root). Load order matters: users → urls → events.

**Adding a new model:** create file in `app/models/`, import it in `app/models/__init__.py`, run `db.create_tables([NewModel], safe=True)`.

**Adding a new blueprint:** create file in `app/routes/`, import and register it in `app/routes/__init__.py`.
